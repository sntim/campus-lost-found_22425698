# FindBack User Manual

## 1. Accessing FindBack

Open the deployed FindBack URL in a modern browser. Public visitors may browse reported items. Select **Sign in** when you need to report property, submit a claim, view personal activity, or administer the service.

## 2. Browsing Reports

Select **Browse** from the navigation. Use the search field for words in an item title, description, or location. Narrow results with category, exact status, and from/to date filters. Choose **Clear** to remove filters. Select an item card to open its details.

## 3. Reporting a Lost or Found Item

After signing in, select **Report lost** or **Report found**. Enter a clear title, a useful description, category, date, and campus location. You may attach one PNG, JPEG, or WebP image up to 4 MB. Select **Publish report**. A confirmation toast means the report was accepted; it will appear under **My profile**.

Do not include passwords, complete identity-card numbers, or other sensitive details in the public description. Keep one distinctive detail private so that a genuine owner can prove ownership during the claim process.

## 4. Submitting an Ownership Claim

Open an active found-item report and select **Submit ownership claim**. Enter evidence that only a real owner should know, such as a private marking, contents, serial-number fragment, or circumstance. The claim is initially **pending**. You may view its current status in **My profile**.

Reporter contact information remains hidden until an administrator approves the claim. An approval produces an in-app notification and permits the approved claimant to view the reporter’s contact detail on that item page.

## 5. Checking Profile and Notifications

Select your account menu, then **My profile**. This page displays reports you created, claims you submitted, current status, administrator notes, and recent notifications. Select the bell icon in the main navigation to read decision notifications; selecting an unread notification marks it as read.

## 6. Administrator Workflow

An account with the `admin` role can open **Admin dashboard** from the account menu. The overview shows key counts. The **Items** tab supports item lifecycle updates using only `lost`, `found`, `resolved`, and `archived`. The **Claims** tab displays evidence and offers **Approve** or **Reject**, with an optional decision note. The claimant is notified in-app after a decision.

## 7. Troubleshooting

If a request fails, read the displayed toast and use the available **Try again** control. Verify your network connection, confirm that you are signed in, and ensure an image has an accepted format and size. If you believe a claim decision is incorrect, contact the campus lost-property administrator through the institution’s normal support channel.
